# siteArm — Gestion des membres de l'Armée du Salut (Bénin)

Site web en français, pensé pour le téléphone, pour gérer les membres de l'église : matricules,
parcours entre paroisses, bureaux, mutations, sanctions, puis grades, événements, messages
officiels et médias.

- Cahier des charges (module 1) : [`docs/cahier-des-charges-module1.pdf`](docs/cahier-des-charges-module1.pdf)
- Plans de réalisation : [`docs/superpowers/plans/`](docs/superpowers/plans/)
- Guide de maintenance : [`docs/guide-maintenance.md`](docs/guide-maintenance.md)

Technologies : Python, Django 5.2, PostgreSQL. Tests : `pytest -q`.
