# Enregistrer les nouveaux membres de votre région — fiche pour les bureaux régionaux

## 1. Obtenir le modèle

Le Secrétaire national vous envoie le **modèle Excel officiel de votre région**
(`modele-membres-region-XX.xlsx`). Utilisez toujours ce modèle : il contient la liste de **vos**
paroisses.

## 2. Remplir le modèle

- Feuille **« Membres »** : **une ligne par membre**, à partir de la ligne 2.
- **Ne touchez pas aux en-têtes** de la ligne 1 (ne les déplacez pas, ne les renommez pas).
- Les colonnes **rouges** (marquées d'un `*`) sont **obligatoires** : Nom, Prénoms, Sexe,
  Téléphone, Année d'intégration, Paroisse d'intégration.
- **Sexe** : `M` ou `F`.
- **Date de naissance** : `JJ/MM/AAAA` (exemple : `01/05/1990`). Une année seule (`1990`) est refusée.
- **Année d'intégration** : l'année du reçu de consécration ou d'intégration, sur 4 chiffres.
- **Paroisse d'intégration** : choisissez-la dans la liste déroulante.
- **Catégorie** : laissez vide pour un **membre actif** ; sinon choisissez « Membre d'honneur » ou
  « Membre sympathisant ».
- **Grade** (facultatif) : laissez vide pour un **nouveau membre** (il sera **Camarade**). Pour un
  membre **déjà gradé**, choisissez son grade dans la liste (ou écrivez-le : « Capitaine »,
  « Soldat de 3e classe »…) et indiquez dans **Date du grade** le jour où il l'a reçu
  (`JJ/MM/AAAA`). Un ancien fichier sans ces deux colonnes reste accepté.
- **NPI** (facultatif) : 10 chiffres.
- 2 000 lignes au plus par fichier. Au-delà, faites plusieurs fichiers.

## 3. Envoyer

Envoyez le fichier rempli au **Secrétaire national**. Il le dépose sur le site, vérifie chaque
ligne et vous renvoie la **liste récapitulative** (nom → matricule) et les **fiches
d'identification**.

## Erreurs fréquentes

| Message affiché au Secrétaire national | Ce qu'il faut corriger |
|---|---|
| « Ce champ ne peut pas être vide. » | Une colonne rouge est vide. |
| « Date de naissance : date invalide, écrivez JJ/MM/AAAA » | Écrire la date complète, ex. `05/07/1975`. |
| « « … » n'existe pas dans la région … » | Choisir la paroisse dans la liste ; vérifier qu'elle est bien dans votre région. |
| « Numéro de téléphone invalide » | Chiffres, espaces et `+` uniquement. |
| « Le NPI comporte 10 chiffres. » / « Ce NPI est déjà utilisé » | Vérifier le NPI ou laisser la case vide. |
| « Doublon possible » | La personne semble déjà inscrite (ou figure deux fois dans le fichier) : le Secrétaire national décide. |
