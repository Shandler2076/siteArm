# 09 — Payer par mobile money

**Pour qui :** tout membre ; le Trésorier de la paroisse pour les membres qui lui remettent des
espèces.

> Un seul numéro, au nom du **Bureau national**. Le paiement **part toujours du site** : c'est ce qui
> permet d'enregistrer exactement qui a payé quoi. Les frais de la plateforme sont à la charge du BN.
> **Sur le site d'essai, la plateforme est simulée : aucun argent réel.**

## Payer mes mois
1. **Mes cotisations → Payer par mobile money** (ou menu **Payer (mobile money)**).
2. Choisissez le **nombre de mois**. Vos plus anciens mois dus sont payés en premier.
3. Confirmez sur votre téléphone avec votre code secret. Le site ne voit jamais ce code. Sur le site
   d'essai : bouton « Confirmer le paiement (simulation) ».
4. Les mois sont **payés aussitôt**, sans validation du circuit, et votre **reçu** est disponible.

## Payer pour un autre membre
Pour un membre âgé, sans téléphone ou sans Internet. **N'importe quel membre** peut le faire.
1. **Payer pour un autre membre**, puis saisissez son **matricule**.
2. Vérifiez la confirmation : grade, prénom, initiale du nom et paroisse (ex. « Soldat Albert A. —
   Paroisse de GBOA »). Rien de plus n'est montré.
3. Choisissez le nombre de mois (ou une cotisation spéciale), puis payez.
4. Le paiement est **au nom du membre aidé** : c'est lui qui reçoit le reçu. Sa paroisse est
   avertie, pour pouvoir lui remettre le reçu imprimé.

## Trésorier de paroisse : payer pour plusieurs membres
Les membres vous remettent leurs espèces. Vous seul les portez sur le site.
1. **Trésorerie → Trésorerie du bureau → Payer pour des membres**.
2. Pour chaque membre, indiquez le **nombre de mois**. Un champ de recherche aide à trouver un membre.
3. Payez le tout en une fois au numéro du BN. Chacun reçoit son reçu.

Plus aucune espèce ne circule entre la paroisse et le circuit. Le BN reverse chaque mois les parts
(voir le guide 11).
