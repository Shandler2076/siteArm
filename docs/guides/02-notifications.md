# 02 — Les notifications

**Pour qui :** tout le monde.

1. La cloche 🔔 en haut de l'écran montre le nombre de notifications **non lues**.
2. Ouvrez **Notifications** : la liste s'affiche, les plus récentes d'abord.
3. **Touchez une notification** : elle est marquée comme lue et vous arrivez **directement sur la
   page concernée**. Exemples :
   - une convocation vous mène à « Mes événements », sur cet événement ;
   - un paiement vous mène à « Mes cotisations » ou à la quittance ;
   - un nouveau membre, une sanction ou une décision vous mènent à la fiche du membre concerné
     (seulement si vous avez le droit de la voir) ;
   - une demande de mutation vous mène à la demande.
4. Pour une simple information, vous restez sur la liste.
5. Le bouton **« Tout marquer comme lu »** vide le compteur d'un coup.

Si vous avez un e-mail enregistré, les notifications vous sont aussi envoyées par e-mail. **Aucun
mot de passe n'est jamais envoyé par e-mail.**
