# 01 — Le menu et la navigation

**Pour qui :** tout le monde.

## Où est le menu ?
- Sur téléphone : bouton **☰ Menu** en haut à gauche.
- Sur ordinateur : toujours visible à gauche.

## Comment il est rangé
Le menu est rangé par **thèmes**. Chacun ne voit que les groupes de ses droits :

| Groupe | Contenu |
|---|---|
| **Mon espace** | Accueil, ma fiche, ma photo, mes coordonnées, mes cotisations, payer (mobile money), mes événements, notifications, protection des données |
| **Gestion des membres (BN)** ou **Mon bureau** | Membres, anciens membres, demandes, vérifier un membre ; pour le BN : enregistrer, lots, photos à valider, décisions |
| **Listes et statistiques** | Listes, statistiques, tranches d'âge |
| **Grades** | Éligibles au grade suivant, promotions en série (BN) |
| **Cotisations mensuelles** | Tableau de bord, parts reçues, réglages (BN) |
| **Trésorerie** | Trésorerie du bureau ; pour le BN : cotisations spéciales, numéros des trésoriers, reversements mensuels |
| **Événements** | Événements nationaux (BN) |
| **Bureaux et droits** | Installer un bureau, fonctions et droits, mandats à échéance (BN) |
| **Contrôle** | Journal (BN) |

## Bon à savoir
- Les groupes sont **repliés** : touchez le titre d'un groupe pour le déplier.
- La page où vous êtes est **mise en évidence** : fond bleu marine, barre dorée à gauche. Son groupe
  reste ouvert, même sur une sous-page (par exemple la fiche d'un membre ouverte depuis « Membres »).
- À chaque page, le menu se place de lui-même sur la rubrique en cours.
